# Demonstration Video Recording Plan & Script (60–90 Seconds)

**Project:** Techfest IIT Bombay — Landing Page Redesign (2026–27 Edition)  
**Concept:** THE FUTURE IS BUILT HERE  
**Target Platform:** Desktop Browser (1920x1080 or 1440x900) + Mobile Viewport Mode  
**Total Target Duration:** 60 to 90 seconds  

---

## 1. Pre-Recording Checklist

- [ ] Ensure development server is running (`npm run dev`) or production preview (`npm run preview`).
- [ ] Open browser at `http://localhost:3000/` (or deployed URL).
- [ ] Set browser zoom to 100%.
- [ ] Close extraneous browser tabs and mute system notifications.
- [ ] Prepare recording software (OBS Studio, Loom, QuickTime, or Windows Game Bar `Win + G`).
- [ ] Test audio/mic if providing spoken commentary (or prepare clean electronic ambient background music).

---

## 2. Minute-by-Minute Demonstration Script

### Segment 1: Hero & Identity (0:00 – 0:18)
- **Visual:** Start at the top of the page.
- **Actions:**
  - Highlight the minimal precision navigation bar with the `[IIT BOMBAY // 2026–27]` wordmark and `EDITION 29 // LIVE` telemetry indicator.
  - Showcase the oversized kinetic typography: **"THE FUTURE IS BUILT HERE"**.
  - Point out the 2D SVG vector trajectories, radar reticles, and atmospheric radial illumination (highlighting zero 3D/WebGL bloat).
  - Hover over the primary `REGISTER FOR TECHFEST 2026–27` CTA and secondary `EXPLORE FESTIVAL VERTICALS` anchor.
- **Narrative (Voiceover):**  
  *"Welcome to the redesigned landing page for Techfest IIT Bombay, Asia's largest science and technology festival. Our concept, 'The Future is Built Here', merges editorial Swiss typography with high-precision avionics telemetry, operating on 100% pure two-dimensional vectors without heavy 3D overhead."*

### Segment 2: Festival Heritage & Asymmetric Editorial Grid (0:18 – 0:32)
- **Actions:**
  - Smoothly scroll into **Architecture & Heritage** (`#about`).
  - Demonstrate the scroll-triggered reveals (`IntersectionObserver`).

- **Narrative (Voiceover):**  
  *"Section one establishes Techfest’s deep institutional heritage at IIT Bombay’s Students Activity Centre in Powai, featuring verified statistics and official global endorsements."*

### Segment 3: Discovery Matrix & Interactive Filter Controls (0:32 – 0:50)
- **Actions:**
  - Scroll into **Discovery Portal** (`#discover`).
  - Click through the category filter pills: `All Verticals` -> `Competitions` -> `Workshops` -> `Exhibitions` -> `Keynotes`.
  - Show the dynamic, instantaneous transition between verified events like *International Robowars*, *Meshmerize*, *ZeroCode AI*, and certified *AI & Deep Learning* workshops.
  - Hover on the `Early Bird Pass` badge and rulebook destination actions.
- **Narrative (Voiceover):**  
  *"The Discovery Matrix allows prospective competitors and attendees to effortlessly filter between technical competitions, IIT Bombay certified workshops, global robotics exhibits, and Nobel Laureate lectures, with direct links to verified official destinations."*

### Segment 4: Engineering Crucible — Featured Innovation HUD (0:50 – 1:08)
- **Actions:**
  - Scroll into **Engineering Crucible** (`#robowars`).
  - Click through the interactive spotlight tabs: *Combat Robotics*, *Unitree G1 Humanoid*, *NASA Astrobee*, and *ZeroCode Agentic AI*.

## 3. Post-Recording Sharing Instructions

1. Export the recording as MP4 (1080p, 60fps recommended).
2. Upload the MP4 video to **Google Drive**.
3. Right-click the uploaded file in Google Drive, select **Share**, and set General Access to **"Anyone with the link can view"** (Viewer permission).
4. Copy the public link to submit alongside the GitHub repository URL.
